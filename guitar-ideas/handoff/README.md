# 📦 Handoff pack — index & how to start

This folder is the portable package for a **new AI session** to build the project. The plan is simple: **website first, then the easiest applications, one per session.**

## How to start the new session (2 steps)

1. In the new session, attach or paste: **`HANDOFF.md`** + **`ideas.html`** (the other files are there if the session wants depth).
2. Paste **prompt P1** from `kickoff-prompt.md` — it tells the session to build the starter website now, then add the first easy app (#131 Repair Diagnostic Wizard).

**Later sessions:** paste **prompt P2** with the next number from the ladder (one app per session). If a session can't take attachments, use **P4**.

## The files

| File | What it is |
|---|---|
| **HANDOFF.md** | The build brief for the AI session: mission, constraints, **the build order (Phase 1 website → Phase 2 apps easiest-first)**, definitions of done, the €0 stack, conventions, do-nots. **Start here.** |

**Phase 1 — starter website** (hub + PWA + tool registry + deploy).

**Website first. Then the easiest apps. One per session. €0, personal use, local-first, deployed after every step.**
